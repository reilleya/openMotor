openMotor is a desktop application for rocketeers who want to estimate chamber pressure and thrust before building a motor. It handles arbitrary grain geometries using the Fast Marching Method, not just the simple ones.

About

What this is, and what it isn't.

openMotor estimates internal ballistics for solid rocket motors. You feed it your propellant properties, grain geometry, and nozzle specs. It gives you chamber pressure and thrust curves over the burn. It won't design the rest of your rocket, and it won't fly it for you. It does one thing: tells you what your motor is likely to do.

The math comes from George Sutton's Rocket Propulsion Elements and Richard Nakka's website. The software is Python, with some Cython for the parts that need to be fast. The source is there so you can check it. You don't have to trust us.

If you build motors and want to reduce the guesswork, this is a tool worth having.

Capabilities

What you can do with it.

01

Model arbitrary grain shapes

Most grain geometry calculators only handle cylinders. openMotor uses the Fast Marching Method to compute regression for any core shape you can draw: BATES, Finocyl, Star, custom DXF imports, whatever you lay out.

02

Define your own propellants

The propellant editor takes burn rate, density, flame temperature, molecular weight. As many propellants as you want. No locked database. You own the numbers.

03

See the grain regress in real time

The grain editor shows how the propellant burns out as the burn progresses. Tweak geometry, watch the regression, cut down on the iterations before you mill any aluminum.

04

Work in metric or imperial

Switch between systems at any time. The UI handles both without converting your files.

05

Export and import

ENG file export for flight simulators. Burnsim import and export so you can compare results or migrate from an existing workflow.

06

Save, load, undo, redo

Designs save to YAML files with a .ric extension. Full undo/redo stack. Motor files are plain text under the hood if you ever need to edit them directly.

Under the hood

How the regression works.

Solid rocket propellant burns inward from the surface. Modeling how that surface moves over time is called "regression." For simple cylindrical bores this is trivial. The radius grows linearly. For anything more complex (Star, Finocyl, irregular cores), the surface topology changes in ways that are hard to write down with a formula.

openMotor uses the Fast Marching Method to track the burning surface. The burn rate at each point depends on local pressure. Pressure depends on the total burn rate. These two are coupled, so FMM solves the resulting level-set equation without needing to remesh.

The core computation is in motorlib/, with Cython accelerations in mathlib/.

Download

Get started.

Pre-built release

Download the latest release for Windows, macOS, or Linux. Unzip and run. No install needed.

Build from source

Clone the repo, set up a Python 3.10+ venv, install requirements, run the setup scripts, then python main.py.

# Clone and set up
git clone https://github.com/reilleya/openMotor.git
cd openMotor
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Build UI files (requires Qt Designer + pyuic6)
python setup.py build_ui

# Build Cython extensions
python setup.py build_ext --inplace

# Run
python main.py
